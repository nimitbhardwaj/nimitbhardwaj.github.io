# nimitbhardwaj.github.io

Personal site and blog. Built with [Astro](https://astro.build) + the [AstroPaper](https://github.com/satnaing/astro-paper) theme.

```bash
bun install
bun run dev      # http://localhost:4321
bun run build
```

Posts: `src/content/posts/*.md`. About page: `src/content/pages/about.md`. Site settings: `astro-paper.config.ts`.
